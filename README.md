# AI-Supported Thoracic Surgery Cohort Project

## Overview

This project aims to analyze a 10-year thoracic surgery cohort using AI-supported methods.

The dataset includes:
- ~15,000 patients
- Longitudinal clinical data
- Detailed pathology reports
- Potential tumor DNA / molecular data layer

## Vision

To transform a clinically collected dataset into a high-value scientific and decision-support system.

## Key Idea

Clinical data shows what happened.  
Molecular data may explain why it happened.

## Focus Areas

- Complications analysis
- Survival and outcomes
- Risk stratification
- Tumor DNA / molecular interpretation

## Project Structure

- docs/ → concept documents
- data/ → future datasets
- scripts/ → processing tools
- outputs/ → results

## Status

Early stage – conceptual and structural development.
